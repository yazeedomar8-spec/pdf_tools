## التجهيز الأولي (مرة وحدة بس، قبل استخدام أي أداة)

```
py --version
```
لازم يطلع لك رقم إصدار. لو ما اشتغل، حمّل بايثون من الموقع الرسمي:
https://www.python.org/downloads/

### 2. ثبّت المكتبات المطلوبة
```
py -m pip install pywin32 pypdf
```

## الأداة الأولى: تحويل ملفات Excel إلى PDF
**الملف:** `excel_to_pdf_via_excel.py`

تحوّل مجموعة ملفات Excel داخل فولدر معيّن إلى PDF دفعة وحدة، باستخدام برنامج Excel نفسه (يعطي أعلى جودة ومطابقة كاملة للتنسيق الأصلي).

**الشرط:** لازم يكون عندك Microsoft Excel مثبت فعلياً على جهازك.

### طريقة الاستخدام
1. افتح الملف بمحرر نصوص (Notepad) وعدّل هذا السطر بمسار فولدر ملفات الإكسل:
   ```python
   INPUT_FOLDER = r"C:\Users\YourName\Desktop\ExcelFiles"
   ```
2. شغّل من PowerShell:
   ```
   py excel_to_pdf_via_excel.py
   ```
3. النتيجة: ملفات PDF تطلع في فولدر جديد اسمه `PDF_Output` جوا نفس المكان.

## الأداة الثانية: استخراج أو حذف صفحات من PDF
**الملف:** `pdf_tool.py`

تشتغل على كل ملفات PDF داخل فولدر معيّن دفعة وحدة، وتقدر:
- **تستخرج** صفحة أو عدة صفحات من كل ملف (وتهمل الباقي)
- **تحذف** صفحة أو عدة صفحات من كل ملف (وتحتفظ بالباقي)

### طريقة الاستخدام
1. عدّل هذا السطر بمسار فولدر ملفات الـPDF:
   ```python
   INPUT_FOLDER = r"C:\Users\YourName\Desktop\MyPDFs"
   ```
2. شغّل من PowerShell:
   ```
   py pdf_tool.py
   ```
3. بيسألك تفاعلياً:
   - **استخراج ولا حذف؟** اكتب `1` للاستخراج أو `2` للحذف
   - **أي صفحات؟** اكتب حسب الحاجة:

   |        الحالة           |      مثال |
   |------------------|-------------------|
   |   صفحة وحدة     |          `5`      |
   |  مدى متتالي     |          `3-6`    |
   |صفحات متفرقة     |         `1,3,7`   |
   |       خليط       |         `1,3-5,9` |

4. النتيجة تطلع في فولدر `Extracted` (للاستخراج) أو `After_Delete` (للحذف).

## ملاحظات عامة
- الأداتين ما يعدّلن على ملفاتك الأصلية أبداً — دايماً يطلعن نسخة جديدة في فولدر منفصل.
- لو ملف PDF مشفّر بكلمة مرور، الأداة الثانية بتحذرك وتتخطاه بدل ما تطلع نتيجة خربانة.
- لو صار أي خطأ وقت التشغيل، انسخ نص الخطأ اللي يطلع في PowerShell وارجع للمحادثة مع Claude لحله.
